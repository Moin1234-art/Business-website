Cloud Sync

Keep the office computer and the phone showing the same register.

Sync works through one file kept in the office's own cloud folder — Google Drive, OneDrive, Dropbox, or even a pen drive or shared network folder. Each device reads that file, merges it with its own records, and writes the result back. Nothing is sent to any other company's server, and no account or password is needed here.

How to Use This Register

Getting started

Open Property Register and press + Add Property. Fill in the details of the property and press Save Property. Only the village, tehsil and nature of the property are compulsory — every other field may be filled in later as records become available.

Finding a property

Type any part of the property ID, khasra number, village name, occupant's name or file number in the Search box. The list narrows down as you type. The three drop-downs beside it filter by tehsil, status and nature of property. Click any column heading to sort by that column.

Editing and deleting

Every row has Edit and Delete buttons at the right end. Deletion asks for confirmation and cannot be undone — restore from a backup file if a record is removed by mistake.

Printing a report

Go to Reports, choose the tehsil and status you need, press Generate Report, then Print / Save as PDF. The printed page carries the office heading and signature lines, and totals are shown at the bottom of the table.

Geo-tagging a property

Standing at the property, open it for editing and press Capture Location under Geo-tagging. The app reads the coordinates from the phone and shows how accurate the reading is; press Save Property to keep it. The register then shows that property as Tagged, and Reports → Geo-tagging progress lists whatever is still to be done. Coordinates can also be typed in by hand.

The property file — rent and inspections

Each row in the register has a File button. It opens that property's file, holding three things:

Rent demanded. Add each demand as it is raised, with the period it covers. Receipts issued. Add every payment with its receipt number, date and mode. Inspections. Add the date, the officer, the condition of the property and what was found.

Arrears are then worked out by the app — opening balance, plus everything demanded, less everything received — so the figure can always be traced back to entries instead of being typed in from memory. Any arrears figure entered before this became the opening balance, so nothing already recorded was lost.

Reports for the office

Register of properties is the full register. Rent defaulters lists everyone in arrears, largest first, with their contact details, for a recovery drive. Geo-tagging progress shows how many properties are tagged and lists those still pending. Weekly progress return summarises the week's receipts, collections, inspections and tagging alongside the standing position.

Using it on two devices

Go to Backup & Data → Cloud Sync. On the first device press Create Sync File and save it inside the office's cloud folder — the Google Drive, OneDrive or Dropbox folder already in use, or a folder on a shared drive. On every other device press Use Existing Sync File and pick that same file. From then on both devices show the same register: each one merges the file with its own records a few seconds after any change, and again whenever it is opened.

Entries made on two devices at the same time are all kept — nothing is thrown away. If a property is edited in both places, the more recent edit is the one kept. If both devices happen to give a new property the same number, one of them is renumbered automatically so no two properties share an ID.

No account or password is needed here, and nothing is sent to any company running this register. Whichever cloud folder is chosen does the carrying.

Deleted records

Deleting a property does not destroy it. It moves to Deleted Records under Backup & Data, where it can be restored. Keeping it there is also what tells the other device that the property was deleted, so it does not reappear at the next sync.

Keeping records safe

The register works without internet and keeps its data on this computer. Go to Backup & Data and press Download Backup File at the end of each day. Keep the downloaded file on a pen drive or another folder. To move records to a new computer, copy this file along with the backup, open the file there, and use Restore from File.

Area measurement

Area is entered in kanal and marla (20 marla = 1 kanal). Enter the marla portion only up to 19; whole kanals go in the kanal box.

Nothing is sent anywhere

This is a standalone file. No information leaves this computer, and no internet connection is needed at any point.

How to Use This Register

Getting started

Open Property Register and press + Add Property. Fill in the details of the property and press Save Property. Only the village, tehsil and nature of the property are compulsory — every other field may be filled in later as records become available.

Finding a property

Type any part of the property ID, khasra number, village name, occupant's name or file number in the Search box. The list narrows down as you type. The three drop-downs beside it filter by tehsil, status and nature of property. Click any column heading to sort by that column.

Editing and deleting

Every row has Edit and Delete buttons at the right end. Deletion asks for confirmation and cannot be undone — restore from a backup file if a record is removed by mistake.

Printing a report

Go to Reports, choose the tehsil and status you need, press Generate Report, then Print / Save as PDF. The printed page carries the office heading and signature lines, and totals are shown at the bottom of the table.

Keeping records safe

The register works without internet and keeps its data on this computer. Go to Backup & Data and press Download Backup File at the end of each day. Keep the downloaded file on a pen drive or another folder. To move records to a new computer, copy this file along with the backup, open the file there, and use Restore from File.

Area measurement

Area is entered in kanal and marla (20 marla = 1 kanal). Enter the marla portion only up to 19; whole kanals go in the kanal box.

Nothing is sent anywhere

This is a standalone file. No information leaves this computer, and no internet connection is needed at any point.
